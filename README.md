# 个人测试型开发记忆体

> **一套以"活记忆流动"为核心的本地优先 AI 记忆系统**
> 记忆不是被"查"出来的，是被当前的思考"震"出来的。

## 这是什么

当前主流 AI 记忆系统（Mem0 / Zep / 向量库 + 图）的范式是 **"库 + 检索"**：记忆是数据库里的条目，提问时检索 top-K 塞进上下文。

本项目走的是另一条路 —— **"活记忆流动"**：

- 记忆不是被"存"进仓库 —— 是 **沉积**在河床上
- 河流过时，河床自然带起沉积物（**认知循环运转时记忆自然跟着流动**）
- 每条记忆有 **活性**（流过就热、久不流就凉），但 **只有深浅、没有删除**
- 想起一个涟漪会带起一片（联想），而查一个词只命中一条（检索）

**零外部模型依赖**（无 embedding API、无 LLM 调用）、**纯标准库**、**本地优先**、**每个数字可复现**。

## 核心特性

| 特性 | 说明 |
|---|---|
| 🧠 **活记忆** | 热度衰减（λ=0.10/天）+ 点亮脉冲（+0.3）+ 保护地板 —— 记忆会"凉"但永不删除 |
| 🌊 **五通道召回** | 点亮（精确）/ 联想（蜘蛛网多跳）/ 预感（接续）/ 思考预热（主动）/ 二次补充（话题切换） |
| 🕸️ **蜘蛛网** | 概念网络 + 关系类型化（父子/同义/因果/共现）+ Hebbian 自生长 |
| 🔒 **记忆私域** | 多 owner 隔离，数据本地，不依赖云服务 |
| 🧬 **写入五道闸** | 空壳过滤 → 内容去重 → 记忆进化 → 核心身份 → 标准对象 |
| 📊 **使用账本** | 成绩单（确认+2/纠正−2/点亮+1）+ 经验预检 + 认知画像 |
| ⚡ **零依赖** | Python 标准库 + SQLite（含 FTS5），无第三方包 |
| ✅ **可复现** | 46+ 验证脚本，所有性能/质量数据标注测试条件 |

## 快速开始

```bash
# 环境：Python 3.11+（无需 pip install 任何东西）

# 1. 写入一条记忆
python memory.py 写入 "父亲说：记忆不是被检索的，是被思考牵引的" --tags "父令,哲学"

# 2. 召回
python memory.py 召回 "记忆范式"

# 3. 点亮一个概念（精确命中 + 涟漪扩散）
python memory.py 点亮 "记忆"

# 4. 联想（沿蜘蛛网多跳扩散）
python memory.py 联想 "父亲"

# 5. 全览（模块地图 + 数据账本）
python memory.py 全览
```

数据默认存储在 `sun_memory/data/sunmem.db`（可用环境变量 `SUNMEM_DB` 覆盖）。

### 记忆流动

```
念头（当前思考）
   ↓ 概念提取
点亮（精确命中 → 活性 +0.3 脉冲）
   ↓ 涟漪
联想（沿蜘蛛网丝线多跳，按权重衰减）
   ↓ 汇聚
注入（按激活强度排序 → 进入认知循环）
   ↓ 反馈
巩固（被用到的记忆 hit_count+1 / 节律续热 / 成绩单记账）
```

## 实测数据

> 完整数据与方法见 [docs/技术白皮书](docs/技术白皮书_v1.1.md)，所有数字标注测试条件。

**规模**（实机统计）：4,471 条记忆 · 19 张表 · 56.3 MB · 蜘蛛网 6,888 节点 / 34,845 条丝线 / 2,221 段落节点

**性能**（同上规模实测）：

| 操作 | 延迟 |
|---|---|
| 点亮（精确命中） | **0.09 s** |
| 预感召回 | **0.12 s** |
| 联想召回（多跳） | **0.47 s** |
| 统一召回 | **1.06 s** |

**召回质量**（诚实标注）：

| 测试 | 结果 | 说明 |
|---|---|---|
| **中文召回（主场）** | **96.7%** | ✅ **中文是本系统的主场**（结构召回：概念+蜘蛛网+活性）；⚠️ 自建测试集·非标准基准，不可对标 LongMemEval |
| **英文召回（客场）** | 27–32% | ⚠️ **真实短板**——英文缺向量语义层（保持零外部 API 的代价） |
| 双通道融合 MRR | 0.688 | 字面 + 无模型向量 |

> **一句话**：**中文强、英文弱** —— 中文靠"结构 + 活性"召回（96.7%），英文靠字面匹配（27–32%）；短板补法是可选的本地小模型向量层，不是中文的问题。

## 设计哲学

1. **记忆不删** —— 只有深浅，没有删除（outdated 标记 / 沉底 / 骨架化，原文永存）
2. **记忆私域** —— 记忆是拥有者的私产（多 owner 隔离，本地存储）
3. **验证留痕** —— 每个数字必须可复现（所有数据标注测试条件）
4. **内核求简、素材求丰、边界守严** —— 动力学内核简单，素材丰富，边界严格

## 与外部系统对照

| 系统 | 范式 | 本系统差异 |
|---|---|---|
| Mem0 | 库 + 检索 + LLM 提取 | 本系统零 LLM 依赖 + 活记忆（热度/节律/账本） |
| MemPalace | 向量语义检索 | 本系统**暂无向量层 → 英文（客场）弱是真实差距**；**中文（主场）靠结构召回 96.7%**；多"活性/巩固/私域"维度 |
| HippoRAG 2 | 知识图谱 + PPR 激活传播 | 同构（蜘蛛网 = 图 + 权重 BFS），本系统加段落节点层 |
| Google RMM | 归因驱动奖励 + 可微重排 | 本系统有成绩单雏形，**缺引用驱动自动归因与可学习重排**（诚实差距） |

**定位**：本系统不是"更好的通用 RAG"，而是 **"能记住、会遗忘、可审计、在你自己的机器上活的记忆体"**。

## 诚实边界

- ❌ **英文召回弱**（LongMemEval 27–32% · 客场短板）
- ❌ 概念提取为规则式（非 LLM）
- ❌ 单机 SQLite 上限（超大规模需架构升级）
- ❌ 中文**暂无外部标准基准可对标**（行业空白）—— **是"没有中文的考卷"，不是中文能力弱**（中文主场自建集 96.7%）
- ❌ 未实现自动归因 / 可学习重排
